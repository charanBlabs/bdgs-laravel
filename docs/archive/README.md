- Brainstorming notes and raw meeting transcripts.

Rules:
- **Read-only.** If something here is wrong or outdated, don't fix it — capture the correction as a living update in `../knowledge-graph.md` or a new record in `../decisions/`.
- Nothing here is a source of truth. The live truth is `knowledge-graph.md`, `taxonomy.md`, `decisions/`, and `progress.md`.
- Keep original filenames and dates so history stays traceable.
