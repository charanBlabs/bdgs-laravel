✓ DO
Use min-height on variable content. Let content determine height.

Use clamp() for fluid type — headings scale smoothly without media queries.
✕ DON'T
Don't use fixed height: 480px on cards with variable copy — content will overflow or clip.

Don't override heading font-size in @media queries.
✓ DO
Use max-width + width: 100% on layout containers.

Use padding-inline: var(--gutter) for fluid side padding.
✕ DON'T
Don't use overflow-x: hidden on body — find and fix the overflowing element instead.

Don't use 100vh with capped content sections.
06

Accessibility

Contrast — WCAG AA

✓ Body text on white: 4.5:1 minimum
✓ Large text / UI: 3:1 minimum
✕ Muted text must still pass 4.5:1
✕ Never remove outline without replacement

Focus Ring

Tab through elements to see the coral focus ring. outline: 2px solid var(--bdgs-coral); outline-offset: 2px.

Link element

Mouse clicks suppress the ring via :focus:not(:focus-visible) { outline: none }.

Touch Targets

Minimum 44×44px for all interactive elements on mobile.

44px
Pass — meets minimum
32px
Fail — too small

Respect prefers-reduced-motion on all animations. Text zoom to 200% must not break layout.

07

Voice & Brand

Brand Personality

Anti-fluff — every sentence earns its place with specifics, not vague marketing.
Oppositional — state what we're NOT, then what we ARE, then prove it.
Founder-savvy — speak to BD site owners as business operators.
Outcome-focused — lead with results, not process.
Concrete — numbers, specifics, examples. Never "we help businesses grow."

Copy Rules

✓ WRITE
"500+ directory sites served"

"Your own dedicated BD developer"

"Get Started →"
✕ AVOID
"Comprehensive, robust solutions"

"Affordable, seamless experience"

"Click Here" / "Submit"

CTA Patterns

Every CTA uses verb + benefit + →. Never just "Submit" or "Click Here". Always "Brilliant Directories" in full — never "BD" in customer copy.
